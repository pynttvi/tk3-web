# Upscaled graphics

25 images scaled 4x with nearest-neighbor from this project's current public/assets PNGs.
Original palette colors and alpha are preserved in RGBA PNGs. Original files remain intact.
Use the Upscaled graphics button to switch; default is off. No AI model was used.
Graphics use the same GPL-3.0 licensing and credits as the original assets.
manifest.json records source and output SHA-256 hashes.
